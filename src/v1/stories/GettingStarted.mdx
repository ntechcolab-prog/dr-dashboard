  <li>The app's real <code style={{ background: '#f0f1f2', padding: '0.05rem 0.35rem', borderRadius: '0.3rem' }}>globals.css</code> (Tailwind v4 <code style={{ background: '#f0f1f2', padding: '0.05rem 0.35rem', borderRadius: '0.3rem' }}>@theme</code> tokens) is loaded, so components render with production styling.</li>
  <li>Props use the same mock data and compute helpers as the app (<code style={{ background: '#f0f1f2', padding: '0.05rem 0.35rem', borderRadius: '0.3rem' }}>src/data/mockData</code>, <code style={{ background: '#f0f1f2', padding: '0.05rem 0.35rem', borderRadius: '0.3rem' }}>src/lib/compute</code>).</li>

  <li>Every component has an <strong>autodocs</strong> page: live preview, editable controls, and copyable source.</li>
</ul>
